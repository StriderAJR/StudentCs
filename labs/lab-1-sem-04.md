# Лабораторная работа 4. Анализ журнала событий сервера

## Сложность

2 / 5

## Темы

Циклы, операторы перехода, методы, рефакторинг и улучшение кода.

## Задание

Во время работы игровой сервер ведёт журнал событий. Каждая строка журнала содержит одно событие: подключение игрока, отключение, успешный вход, ошибку, запуск карты, сохранение мира и т.д.

Необходимо разработать программу, которая анализирует журнал событий и формирует итоговый отчёт о работе сервера.

Какие именно сведения должны попасть в отчёт, определите самостоятельно. Например, это могут быть наиболее частые события, количество ошибок, число подключений игроков, время наиболее высокой активности или другие полезные характеристики.

Журнал может содержать произвольное количество записей.

После получения рабочего решения проанализируйте свой код и постарайтесь сделать его более понятным и удобным для сопровождения, не изменяя поведение программы.

## Подсказки

<details>
<summary>Показать подсказки</summary>

- Количество строк в журнале заранее неизвестно.
- Не каждая запись журнала обязательно представляет интерес при формировании итогового отчёта.
- Если в программе появляются большие повторяющиеся фрагменты кода, подумайте, как сделать решение проще и понятнее.

</details>

Добавьте возможность игнорировать некоторые типы событий. Какие именно события можно исключить из анализа, определите самостоятельно.
