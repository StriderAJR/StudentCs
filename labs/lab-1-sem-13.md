
# Лабораторная работа 13. Игровые события

## Сложность

4 / 5

## Темы

Полиморфизм, виртуальные методы.

## Задание

Продолжите разработку игрового мира из предыдущей лабораторной работы.

Теперь каждый игровой объект должен уметь самостоятельно выполнять действия при взаимодействии с игроком.

Например:

- игрок может получать урон;
- монстр начинает атаку;
- сундук открывается;
- дверь открывается или закрывается;
- торговец начинает торговлю;
- портал телепортирует игрока;
- ловушка наносит урон;
- костёр восстанавливает здоровье.

При выборе объекта пользователь должен иметь возможность выполнить взаимодействие с ним.

При этом основная программа не должна знать, с каким именно типом объекта она работает.

Цель работы — перенести выбор поведения в сами игровые объекты. В основном цикле не должно быть проверок конкретных типов объектов, выбирающих действие для каждого типа.

Если для добавления нового типа объекта приходится изменять существующий код программы, попробуйте изменить архитектуру решения.

## Дополнительное задание

Во время разработки игры дизайнеры решили добавить несколько новых типов игровых объектов:

- костёр — восстанавливает здоровье игрока;
- портал — перемещает игрока в другую точку карты;
- ловушка — наносит урон при взаимодействии;
- алтарь — полностью восстанавливает здоровье игрока и снимает все отрицательные эффекты.

Добавьте поддержку этих объектов в программу.

После завершения работы оцените, какие части программы пришлось изменить.

Если для добавления нового типа объекта потребовалось:

- изменять существующие `if` или `switch`;
- дописывать новые проверки типа объекта;
- изменять код главной программы или логику обработки взаимодействия,

попробуйте изменить архитектуру таким образом, чтобы при добавлении нового типа игрового объекта достаточно было создать новый класс и реализовать его поведение.

В идеале после добавления нового объекта изменения должны ограничиваться созданием нового класса и, при необходимости, добавлением новой записи в фабрику или таблицу загрузки карты.
