# Лабораторная работа 5. Менеджер сохранений игры

## Имя

sem-1-lab-05-save-manager

## Сложность

2 / 5

## Темы

Файлы и каталоги, JSON, сериализация, методы, классы, списки.

## Задание

Сохранение игры — это не только имя файла: в нём находятся данные игрового мира и персонажа. Напишите консольную программу, которая читает сохранения в формате JSON, показывает их содержимое и позволяет изменять данные.

Для начала используйте предоставленные [index.json](lab-1-sem-05/index.json) и три файла сохранений: [save-01.json](lab-1-sem-05/save-01.json), [save-02.json](lab-1-sem-05/save-02.json) и [autosave.json](lab-1-sem-05/autosave.json). Скопируйте их в рабочую папку программы, сохранив структуру:

```text
index.json
saves/
  save-01.json
  save-02.json
  autosave.json
backups/
```

`index.json` содержит массив записей. В каждой записи указаны имя сохранения, имя файла и дата последнего изменения индекса. Файлы в каталоге `saves` содержат данные персонажа: имя, карту, координаты, здоровье и инвентарь. Кодировка всех файлов — UTF-8. Поле `updatedAt` в индексе записывайте в формате `yyyy-MM-ddTHH:mm:ss`.

Создайте классы для описания записи индекса, координат и игрового сохранения. Например, сохранение можно представить так:

```csharp
public class SaveData
{
    public string Character { get; set; }
    public string Map { get; set; }
    public Position Position { get; set; }
    public int Health { get; set; }
    public List<string> Inventory { get; set; }
}
```

Добавьте необходимые классы для `Position` и записи индекса. Для чтения и записи используйте библиотеку Newtonsoft.Json.

Реализуйте в классе `Program` следующие статические методы:

- `LoadIndex(string indexPath)` — читает `index.json` с помощью `JsonConvert` и возвращает список записей. Если файла нет или JSON некорректен, выведите понятное сообщение и завершите программу без аварийного завершения.
- `LoadSave(string savesDirectory, SaveEntry entry)` — читает JSON-файл соответствующего сохранения с помощью `JsonConvert` и возвращает объект `SaveData`. Если файл отсутствует или содержит некорректный JSON, сообщите об ошибке.
- `PrintSave(SaveEntry entry, SaveData save)` — выводит имя сохранения, персонажа, карту, координаты, здоровье и предметы инвентаря.
- `FindByName(List<SaveEntry> entries, string name)` — ищет запись по имени без учёта регистра.
- `SaveGame(string savesDirectory, SaveEntry entry, SaveData save)` — сериализует и записывает изменённые данные в JSON-файл сохранения.
- `SaveIndex(string indexPath, List<SaveEntry> entries)` — сериализует список записей обратно в `index.json` как JSON с отступами.
- `CreateBackup(string savesDirectory, string backupsDirectory, SaveEntry entry)` — копирует JSON-файл сохранения в каталог `backups`, заменяя существующую копию.
- `RestoreBackup(string savesDirectory, string backupsDirectory, SaveEntry entry)` — восстанавливает сохранение из резервной копии. Если копии нет, сообщите об этом и ничего не изменяйте.
- `DeleteSave(string savesDirectory, string indexPath, List<SaveEntry> entries, SaveEntry entry)` — удаляет файл сохранения и его запись из индекса. Если файл отсутствует, сообщите об этом; запись из индекса всё равно удалите и сохраните индекс.

Показывайте ошибки отдельно для каждого файла сохранения: если один файл не читается, пользователь должен иметь возможность вернуться в меню и продолжить работу с остальными сохранениями.

В `Main` загрузите индекс и создайте меню со следующими действиями:

1. Показать список сохранений.
2. Посмотреть данные сохранения.
3. Изменить данные персонажа и записать их обратно.
4. Создать резервную копию.
5. Восстановить резервную копию.
6. Удалить сохранение.
7. Выйти.

Для действий с конкретным сохранением попросите пользователя ввести его имя. Если запись не найдена, выведите сообщение и вернитесь в меню. При редактировании предложите изменить карту, координаты, здоровье и предметы инвентаря; пользователь может оставить любое поле без изменений. После редактирования запишите данные сохранения и обновите `updatedAt` в индексе, затем сохраните индекс.

Каталоги `saves` и `backups` программа должна создавать при необходимости. Используйте относительные пути от рабочей папки программы.

## Подсказки

<details>
<summary>Показать подсказки</summary>

- Установите Newtonsoft.Json через NuGet в Visual Studio:
  1. В обозревателе решений щёлкните правой кнопкой по проекту лабораторной.
  2. Выберите **Управление пакетами NuGet...**.
  3. Откройте вкладку **Обзор** и найдите пакет `Newtonsoft.Json` (автор — James Newton-King).
  4. Выберите пакет, нажмите **Установить** и подтвердите изменения, если Visual Studio попросит.
  5. В файлах, где используется библиотека, добавьте `using Newtonsoft.Json;`.
- Чтобы прочитать объект из JSON-строки, вызовите `JsonConvert.DeserializeObject<T>(json)`. Например:

  ```csharp
  string json = File.ReadAllText(path);
  SaveData save = JsonConvert.DeserializeObject<SaveData>(json);
  ```

- Чтобы записать объект в JSON с отступами, вызовите `JsonConvert.SerializeObject(value, Formatting.Indented)`, а результат сохраните через `File.WriteAllText`:

  ```csharp
  string json = JsonConvert.SerializeObject(save, Formatting.Indented);
  File.WriteAllText(path, json);
  ```

- Для массива записей индекса используйте `JsonConvert.DeserializeObject<List<SaveEntry>>(json)` и `JsonConvert.SerializeObject(entries, Formatting.Indented)`.
- Перед чтением или записью файла можно проверить его наличие с помощью `File.Exists`.
- Для копирования файла используйте `File.Copy(sourcePath, destinationPath, overwrite: true)`.
- Координаты удобнее хранить отдельным объектом с полями `X` и `Y`.

</details>
