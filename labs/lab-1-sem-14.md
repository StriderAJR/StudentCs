# Лабораторная работа 14. Генератор отчётов

## Сложность

3 / 5

## Темы

StringBuilder.

## Задание

Вы разрабатываете утилиту для формирования текстовых отчётов о работе игрового сервера.

Отчёт может содержать различную информацию:

- сведения о состоянии сервера;
- список игроков;
- список игровых объектов;
- журнал событий;
- статистику игрового мира;
- другую информацию по вашему выбору.

Все данные должны объединяться в один большой текстовый отчёт, который затем выводится на экран и сохраняется в текстовый файл.

Программа должна позволять:

- сформировать новый отчёт;
- вывести отчёт на экран;
- сохранить отчёт в файл;
- повторно сформировать отчёт после изменения данных.

Во время разработки постарайтесь сделать так, чтобы добавление новых разделов отчёта требовало минимальных изменений существующего кода.

## Исследование производительности

После завершения программы сравните скорость формирования большого отчёта двумя различными способами:

- используя оператор `+`;
- используя `StringBuilder`.

Для этого сформируйте отчёт, содержащий не менее **100 000 строк**.

Для измерения времени рекомендуется воспользоваться классом `Stopwatch`.

Например:

```csharp
using System.Diagnostics;

var stopwatch = Stopwatch.StartNew();

// Формирование отчёта.

stopwatch.Stop();

Console.WriteLine($"Время формирования: {stopwatch.Elapsed.TotalMilliseconds} мс");
```

Для получения более точного результата рекомендуется выполнить формирование отчёта несколько раз.

После завершения эксперимента сравните полученные результаты и попробуйте объяснить, почему один из способов оказался быстрее другого.
