# Лабораторная работа 6. Мониторинг сервера в реальном времени

## Сложность

3 / 5

## Темы

## Задание

Во многих системах мониторинга информация о состоянии сервера отображается в виде графиков, которые обновляются в режиме реального времени.

В рамках этой лабораторной необходимо разработать упрощённую версию такого монитора.

Вам будет предоставлен готовый класс, который имитирует работу настоящего сервера и позволяет получать текущие значения:

- загрузки процессора;
- использования оперативной памяти;
- температуры процессора.

Каждую секунду программа должна получать новые данные, сохранять историю измерений и отображать её в виде графиков, которые обновляются в режиме реального времени.

Количество одновременно отображаемых измерений определите самостоятельно.

Способ отображения графиков также выбирается самостоятельно.

## Использование готовой библиотеки

Для этой лабораторной вам предоставляется небольшая библиотека, имитирующая работу настоящего сервера. Создайте отдельный файл и скопируйте в него предоставленный код. Также внизу будет пример использования этой библиотеки в вашем коде.

**Важно**

Исходный код этой библиотеки использует конструкции языка, которые вы ещё не изучали. Это нормально.

В данной лабораторной **не нужно разбираться, как она устроена**. Достаточно знать, какие методы предоставляет библиотека и что они возвращают.

Это похоже на использование готовой библиотеки, найденной в интернете или подключённой через NuGet.

```csharp
using System;
using System.Timers;

public class ServerMonitor
{
    private readonly Random _random = new();

    private readonly Timer _timer;

    private double _cpu = 35;
    private double _ram = 42;
    private double _temperature = 48;

    public event Action<double, double, double>? DataReceived;

    public ServerMonitor()
    {
        _timer = new Timer(1000);
        _timer.Elapsed += (_, _) => GenerateData();
    }

    public void Start()
    {
        _timer.Start();
    }

    public void Stop()
    {
        _timer.Stop();
    }

    private void GenerateData()
    {
        _cpu += _random.NextDouble() * 10 - 5;
        _ram += _random.NextDouble() * 6 - 3;
        _temperature += _random.NextDouble() * 4 - 2;

        _cpu = Math.Clamp(_cpu, 0, 100);
        _ram = Math.Clamp(_ram, 10, 100);
        _temperature = Math.Clamp(_temperature, 30, 95);

        DataReceived?.Invoke(
            Math.Round(_cpu, 1),
            Math.Round(_ram, 1),
            Math.Round(_temperature, 1));
    }
}
```

</details>

<details>
<summary>Подсказка: как можно нарисовать график</summary>

Одним из возможных вариантов является построение графика с помощью обычных текстовых символов.

Например, если за последние 8 минут были получены следующие значения загрузки процессора:

```
20 35 45 60 55 70 68 50
```

График может выглядеть так:

```text
70 |           █
60 |         █ █
50 |       █ █ █   █
40 |     █ █ █ █   █
30 |   █ █ █ █ █   █
20 | █ █ █ █ █ █ █ █
   +-----------------
     1 2 3 4 5 6 7 8
```

Это лишь один из возможных вариантов оформления. Вы можете разработать собственный способ отображения графика.

Не обязательно перерисовывать график после каждого нового измерения.

Например, библиотека передаёт новые данные каждую секунду, а график можно обновлять один раз в минуту. В этом случае по оси X будет отображаться история за последние несколько минут, а не за последние несколько секунд.

Для обновления изображения можно воспользоваться методом `Console.Clear()`. Однако полная очистка экрана может вызывать заметное мерцание. Если вам удастся обновлять только изменившуюся часть изображения, результат будет выглядеть значительно лучше, хотя это и не является обязательным требованием.
