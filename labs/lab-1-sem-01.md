# Лабораторная работа 1. Мониторинг игрового сервера

## Сложность

1 / 5

## Темы

Типы данных, числовые типы данных, логический тип данных, преобразование и приведение типов данных, приоритет типов данных, переменные, операторы, арифметические операции, строка.

## Задание

Вы разрабатываете небольшую консольную утилиту для администратора игрового сервера.

Перед началом каждого игрового дня администратор собирает основные характеристики сервера, чтобы убедиться, что он готов принимать игроков.

Разработайте программу, которая получает информацию о состоянии сервера и формирует удобную сводку.

Какие именно характеристики анализировать и какие дополнительные показатели вычислять — определите самостоятельно. Постарайтесь сделать так, чтобы итоговая сводка действительно помогала быстро оценить состояние сервера.

Результат должен быть понятен человеку, который будет использовать программу ежедневно.

## Подсказки

<details>
<summary>Показать подсказки</summary>

- Исходные данные можно получать как из консоли, так и из текстового файла.
- Для чтения из консоли можно использовать `Console.ReadLine()`.
- Для чтения файла можно использовать `File.ReadAllLines()`.
- Любые данные, считанные из файла, сначала являются строками.
- Если необходимо выполнять вычисления, строки потребуется преобразовать в числовые типы данных.
- Подумайте, какие данные должны храниться как целые числа, какие — как вещественные, а какие — как логические значения.
- При вычислениях с вещественными числами учитывайте особенности их хранения и сравнения.
- "Удобная сводка" может представлять собой красиво оформленный вывод в консоль с использованием символов `|`, `-`, `+`, табуляции (`\t`) и других элементов оформления.
- Другой вариант — сохранить результат в отдельный файл, например в формате CSV или любом другом формате, который удобно обрабатывать программам.
- Если результат предназначен человеку, главным критерием должна быть читаемость. Если программе — удобство дальнейшей обработки данных.

</details>

## Дополнительное задание
