# Лабораторная работа 7. Отладка рекурсивного алгоритма

## Сложность

3 / 5

## Темы

Рекурсия, дерево рекурсии, рефакторинг и улучшение кода, отладка.

## Задание

Один из разработчиков начал писать программу, которая строит дерево каталогов по специальному текстовому описанию.

Например, файл

```text
A

BEGIN B
BEGIN C
END

BEGIN D
END
END

BEGIN E
END
```

должен быть преобразован в

```text
A
├─B
│ ├─C
│ └─D
└─E
```

Однако программа работает неправильно:

- некоторые каталоги выводятся не на своём уровне вложенности;
- часть дерева отображается неверно;
- код трудно читать и сопровождать.

В исходной программе специально оставлено несколько ошибок. Не ограничивайтесь исправлением внешнего вида результата: с помощью отладчика проследите изменение `_lineIndex` и `_depth` во время обработки вложенных каталогов.

Ваша задача:

1. С помощью отладчика найти причину неправильной работы программы.
2. Исправить найденные ошибки.
3. Улучшить читаемость программы, не изменяя её поведения.
4. Подготовить краткое описание найденных ошибок и выполненных изменений.

Во время выполнения задания рекомендуется активно использовать режим пошаговой отладки и окно **Call Stack** (Стек вызовов).

## Дополнительное задание

После исправления программы добавьте вывод количества дочерних элементов рядом с каждым каталогом.

Например:

```text
A (2)
├─B (2)
│ ├─C (0)
│ └─D (0)
└─E (0)
```

<details>
<summary>Программа для исправления</summary>

```cs
using System;
using System.IO;

internal class Program
{
    // Current line in file
    private static int _lineIndex;

    // Current nesting level
    private static int _depth;

    // File content
    private static string[] _lines = null!;

    private static void Main()
    {
        _lines = File.ReadAllLines("tree.txt");

        Console.WriteLine(_lines[0]);

        _lineIndex = 1;

        PrintTree();

        Console.ReadLine();
    }

    private static void PrintTree()
    {
        while (_lineIndex < _lines.Length)
        {
            var line = _lines[_lineIndex].Trim();

            if (line == "")
            {
                _lineIndex += 2;
                continue;
            }

            if (line == "END")
            {
                _depth--;

                _lineIndex++;

                return;
            }

            if (line.StartsWith("BEGIN "))
            {
                var name = line.Substring(5);

                Console.Write(GetIndent());
                Console.WriteLine("├─" + name);

                _depth++;

                PrintTree();
            }

            _lineIndex++;
        }
    }

    private static string GetIndent()
    {
        var result = "";

        for (var i = 0; i <= _depth; i++)
        {
            result += "│ ";
        }

        return result;
    }
}
```
</details>
