# Лабораторная работа 11. Инвентарь Terraria

## Имя

sem-1-lab-11-inventory-stacks

## Сложность

3 / 5

## Темы

Перегрузка операторов.

## Задание

Вы разрабатываете систему хранения предметов для игры, похожей на Terraria.

В игре каждый предмет хранится в виде стопки. Например, игрок может иметь:

- 25 блоков камня;
- 40 факелов;
- 120 деревянных блоков;
- 8 железных слитков.

Каждая стопка содержит информацию о типе предмета и его количестве.

Начальные стопки возьмите из [stacks.txt](lab-1-sem-11/stacks.txt). Формат строки: `item|count`, разделитель `|`, кодировка UTF-8.

Программа должна поддерживать следующие возможности:

- создание новых стопок предметов;
- объединение двух стопок одинаковых предметов;
- разделение стопки на несколько частей;
- сравнение стопок между собой;
- вывод информации о стопке.

При проектировании программы постарайтесь сделать работу со стопками максимально естественной и удобной для программиста.

Если некоторое действие невозможно выполнить (например, объединить разные предметы или разделить стопку на недопустимое количество частей), программа должна сообщить об ошибке.

### Один из возможных вариантов работы программы

```text
1 - Создать стопку
2 - Объединить стопки
3 - Разделить стопку
4 - Сравнить стопки
5 - Показать все стопки
0 - Выход
```

---

Например, после объединения

```text
Камень x25
```

и

```text
Камень x40
```

должен получиться результат

```text
Камень x65
```

---

После разделения

```text
Факел x100
```

на четыре части можно получить

```text
Факел x25
Факел x25
Факел x25
Факел x25
```

Если количество предметов не делится нацело, распределяйте остаток по первой стопке: `10 / 3` даёт `4`, `3`, `3`.

---

Подумайте, каким образом сделать так, чтобы код, работающий со стопками предметов, выглядел максимально естественно и напоминал обычные арифметические операции.

Также подумайте, какие операции имеют смысл только для стопок одного и того же типа.

В основной части рекомендуется реализовать следующие операции:

- `+` — объединение одинаковых стопок;
- `-` — уменьшение количества предметов или разделение стопки;
- `==` и `!=` — сравнение стопок;
- `ToString()` — удобное отображение стопки.

## Дополнительное задание

Добавьте ограничение на максимальный размер стопки.

Например:

```text
Камень — максимум 999 предметов.
Факел — максимум 99 предметов.
Железный слиток — максимум 999 предметов.
```

Если после объединения максимальный размер стопки превышен, лишние предметы должны автоматически перейти в новую стопку.

Для этой части используйте отдельный метод, который может вернуть несколько получившихся стопок. Не требуется заставлять оператор возвращать одновременно две стопки.

Например:

```text
Камень x700
+
Камень x500
```

↓

```text
Камень x999
Камень x201
```

Для этой части добавьте метод `SplitWithOverflow`, возвращающий список получившихся стопок.
