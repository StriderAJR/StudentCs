# Лабораторная работа 11. Игровой мир

## Сложность

4 / 5

## Темы

Наследование, иерархия наследования, upcast, downcast.

## Задание

Вы разрабатываете основу игрового движка для двумерной игры.

Игровой мир состоит из карты и различных объектов, расположенных на ней. Например:

- игрок;
- монстр;
- торговец;
- сундук;
- дверь;
- другие объекты.

Каждый тип объекта обладает собственными особенностями. Например, игрок имеет количество здоровья, опыта и золота, монстр — запас здоровья и силу атаки, сундук хранит предметы, а дверь может быть открыта или закрыта.

При этом многие характеристики являются общими для всех объектов. Например:

- координаты;
- отображение на карте;
- возможность взаимодействия с пользователем.

Самостоятельно спроектируйте иерархию классов таким образом, чтобы избежать дублирования кода.

Первоначальное состояние игрового мира должно загружаться из текстового файла. Во время чтения файла программа должна автоматически определить тип каждого объекта и создать экземпляр соответствующего класса.

После загрузки пользователь должен иметь возможность:

- вывести карту на экран;
- выбрать объект по координатам;
- вывести информацию о выбранном объекте;
- изменить состояние выбранного объекта;
- переместить объект в другую клетку карты;
- повторно вывести карту, чтобы увидеть результат изменений.

Если при реализации программы вы обнаружили одинаковый код в нескольких классах, попробуйте изменить структуру программы.

### Один из возможных форматов карты

Карта может храниться в обычном текстовом файле.

Например:

```text
####################
#.................N#
#...............####
#..P...............#
#..........C.......#
#.......M..........#
####################
```

Например:

```text
# - стена
. - пустая клетка
P - игрок
M - монстр
N - торговец
C - сундук
D - дверь
```

При загрузке файла программа должна самостоятельно создать игровые объекты соответствующего типа и разместить их на карте.

---

### Один из возможных вариантов меню

```text
1 - Показать карту
2 - Выбрать объект
3 - Переместить объект
4 - Изменить состояние объекта
0 - Выход
```

После выбора объекта можно запросить координаты.

Например:

```text
Введите координату X:
10

Введите координату Y:
4
```

Если по указанным координатам находится игровой объект, программа должна вывести информацию о нём.

Например:

```text
Сундук

Координаты: (10, 4)
Количество предметов: 5
Открыт: Нет
```

Если объект отсутствует, программа должна сообщить об этом.

---

### Перемещение объекта

После выбора команды можно запросить новые координаты.

Например:

```text
Введите новую координату X:
12

Введите новую координату Y:
3
```

После перемещения рекомендуется сразу вывести карту повторно, чтобы пользователь увидел результат.

---

### Изменение состояния объекта

Разные объекты могут поддерживать разные действия.

Например:

- игрок — получить урон, восстановить здоровье;
- монстр — получить урон;
- сундук — открыть или закрыть;
- дверь — открыть или закрыть;
- торговец — изменить количество золота.

Подумайте, каким образом определить тип объекта, находящегося в выбранной клетке, чтобы выполнить доступные именно для него действия.
