# Лабораторная работа 3. Генератор отчётов для Discord

## Сложность

2 / 5

## Темы

Методы, строка, специальные символы, экранирование, методы и свойства строки, значение `null`, `DateTime`.

## Задание

После завершения игрового события администратор публикует отчёт в Discord.

Чтобы не составлять сообщение вручную каждый раз, необходимо разработать программу, которая автоматически формирует готовый текст отчёта на основе введённых данных.

Какая именно информация должна входить в отчёт — определите самостоятельно. Например, это могут быть название события, дата проведения, количество участников, победитель, продолжительность, призовой фонд, дополнительные комментарии и другие сведения.

В отчёте обязательно должна присутствовать дата проведения события. Для получения или форматирования даты используйте `DateTime`.

Если часть информации отсутствует, итоговое сообщение должно оставаться понятным и аккуратно оформленным.

Структуру сообщения и стиль оформления определите самостоятельно. Получившийся текст должен быть готов к публикации без дополнительного редактирования.
