## Задание

После завершения игрового события администратор публикует отчёт в Discord.

Чтобы не составлять сообщение вручную каждый раз, необходимо разработать программу, которая автоматически формирует готовый текст отчёта по журналу событий.

Используйте [event_server.log](lab-1-sem-03/event_server.log). Каждая строка имеет формат `yyyy-MM-dd HH:mm:ss.fff [level][category] message`: технические маркеры уровня и категории записаны по-английски, текст сообщения — по-русски. Журнал содержит одно игровое событие `Восстание Ледяного Пламени` и технические записи после его завершения. В отчёт включайте только записи от `Событие началось: Восстание Ледяного Пламени` до `Событие "Восстание Ледяного Пламени" закрыто` включительно.

В отчёте обязательно должна присутствовать дата проведения события. Для получения и форматирования даты используйте `DateTime`.

Работайте только с массивом строк `string[]`, циклами, методами и методами класса `string`. Не создавайте свои классы, структуры, списки или словари.

Сформируйте следующий отчёт.

```text
# Итоги события: Восстание Ледяного Пламени

Дата: 01.09.2026
Победитель: Ночные совы
Очки победителя: 2500
Ивентовый предмет: Сердце Эмберфанга
Утешительная награда Железных волков: 800 очков
Предупреждений во время события: 6
Ошибок во время события: 1
```

Все значения, включая имя победителя, извлекайте из лога, а не записывайте константами.

### Какие записи использовать

В каждой строке лога после времени указаны уровень и категория, а затем — сообщение. Для отчёта достаточно просматривать строки события и искать в сообщении характерные фразы.

| Что вывести в отчёте | Где искать в журнале |
| --- | --- |
| Дату | строка с началом события: `Событие началось:` |
| Победителя | категория `Reward`, сообщение с фразой `объявлены победителями события` |
| Очки победителя | категория `Reward`, сообщение с фразой `получили ... очков события` |
| Ивентовый предмет | категория `Loot`, сообщение с фразой `получили ивентовый предмет:` |
| Утешительную награду | категория `Reward`, сообщение с фразой `утешительную награду:` |
| Предупреждения | уровень `Warning` |
| Ошибки | уровень `Error` |

Число строк заранее неизвестно: обрабатывайте весь массив. Учитывайте только записи между началом события и записью о его закрытии; обычная работа сервера после него не относится к отчёту.

## Подсказки

<summary>Показать подсказки</summary>

- Сначала прочитайте файл в массив: `string[] lines = File.ReadAllLines("event_server.log");`.
- Обрабатывайте строки только между маркерами начала и конца события. Для этого используйте переменную `bool isEventRunning`: включите её, когда встретите строку с `Событие началось:`, и выключите после строки с `Событие "Восстание Ледяного Пламени" закрыто`.
-  Победитель заранее неизвестен. Найдите строку, содержащую `объявлены победителями события`. Имя победившего клана находится в сообщении перед текстом ` объявлены победителями`:

  ```csharp
  int messageStart = line.IndexOf("] ") + 2;
  int winnerEnd = line.IndexOf(" объявлены победителями");
  string winner = line.Substring(messageStart, winnerEnd - messageStart);
  ```

  Для приложенного лога этот код вернёт `Ночные совы`, но в программе это значение должно получаться из строки.
- Чтобы найти строку с наградой Ночных сов, проверьте: `line.Contains("Ночные совы получили")`. В логе есть строка `Ночные совы получили 2500 очков события`.
- Число очков можно извлечь без сложных типов. Найдите границы числа с `IndexOf`, получите его с `Substring` и преобразуйте через `int.Parse`:

  ```csharp
  const string startText = "Ночные совы получили ";
  int start = line.IndexOf(startText) + startText.Length;
  int end = line.IndexOf(" очков", start);
  int points = int.Parse(line.Substring(start, end - start));
  ```

- Предмет находится в строке с текстом `Ночные совы получили ивентовый предмет:`. Чтобы получить название, возьмите подстроку после этого текста до конца строки.
- Для подсчёта предупреждений и ошибок пройдите по массиву циклом и увеличивайте счётчики, если строка содержит `[Warning]` или `[Error]`.
- Вынесите повторяющиеся действия в методы, которые принимают `string[]` и возвращают простое значение: `int`, `string` или `DateTime`.
