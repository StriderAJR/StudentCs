## Как читать лекции

Не ограничивайтесь чтением. Для каждого примера полезно:

- предсказать результат до запуска;
- нарисовать, какие значения и ссылки появляются в памяти;
- изменить одно значение и проверить, что изменилось;
- придумать ошибочный ввод или граничный случай;
- объяснить пример своими словами.

Схемы стека и кучи в лекциях являются учебной моделью. Реальный .NET может хранить локальные значения в регистрах, оптимизировать объекты и менять детали размещения. Модель нужна, чтобы понять значения, ссылки, время жизни и копирование данных.
