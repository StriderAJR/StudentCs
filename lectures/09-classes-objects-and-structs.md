# Лекция 9: классы, объекты и структуры

## Класс и объект

Класс — описание устройства сущности. Объект — конкретный экземпляр этого описания.

``` csharp
class Player
{
    public string Name;
    public int Level;
}

Player player = new Player();
player.Name = "Artemis";
player.Level = 12;
```

`Player` описывает поля, а `player` ссылается на созданный объект.

Методы класса объединяют данные и операции над ними:

``` csharp
class Player
{
    public string Name;
    public int Level;

    public void PrintInfo()
    {
        Console.WriteLine($"{Name}, уровень {Level}");
    }
}
```

Вызов `player.PrintInfo()` передаёт методу скрытую ссылку `this` — ссылку на тот объект, через который выполнен вызов. Поэтому метод видит именно поля конкретного игрока.

## Память объекта

Класс является ссылочным типом: переменная обычно содержит ссылку, а данные объекта лежат в куче.

![Переменная-ссылка и объект класса](../img/lectures/09/shared-object.png)

Две переменные могут ссылаться на один объект. Тогда изменение через одну ссылку будет видно через другую.

``` csharp
Player anotherPlayer = player;
anotherPlayer.Level = 20;
Console.WriteLine(player.Level); // 20
```

Присваивание скопировало ссылку, а не объект. Это можно представить так:

![Две ссылки на один объект](../img/lectures/09/shared-object.png)

## Структура

Структура — тип значения. При присваивании структуры копируется её значение.

``` csharp
struct Position
{
    public int X;
    public int Y;
}

Position first = new Position { X = 2, Y = 3 };
Position second = first;
second.X = 99;

Console.WriteLine(first.X); // 2
```

Структура тоже может иметь методы, но обычно её используют как небольшое значение. Если структура содержит ссылку на объект, копируется сама ссылка, а не объект, на который она указывает.

Для небольших значений вроде координат структура бывает удобна. Класс лучше подходит для самостоятельной сущности со сложным состоянием и идентичностью.

## Передача в метод

Структура по умолчанию передаётся копированием значения, класс — копированием ссылки. Это две разные операции, хотя синтаксис вызова выглядит одинаково.

``` csharp
static void Rename(Player player)
{
    player.Name = "Nova";
}

Rename(player);
Console.WriteLine(player.Name); // Nova
```

Метод получил копию ссылки, но обе ссылки указывают на один объект. Если присвоить параметру новый объект, исходная ссылка не изменится:

``` csharp
static void Replace(Player player)
{
    player = new Player();
}
```

Здесь меняется только локальная копия ссылки в кадре метода.

## Когда выбирать класс, а когда структуру

Структура хороша для небольшого значения без отдельной идентичности: координаты, цвет, диапазон. Класс подходит сущности, которую нужно изменять, передавать и узнавать как тот же самый объект. Большая структура тоже копируется, поэтому может быть невыгодна.

## Итог

Класс создаёт объект в куче, а переменная хранит ссылку на него. Структура содержит значение и при присваивании копируется. Это различие объясняет многие неожиданные изменения данных.
