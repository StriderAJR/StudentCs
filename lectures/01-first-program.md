# Лекция 1: первая программа, ввод и вывод данных

## Введение

Любая программа начинается с очень простой вещи: она получает какие-то данные, что-то с ними делает и показывает результат.

Например, игровой профиль можно представить так:

- игрок вводит имя и уровень;
- программа запоминает эти значения;
- программа выводит аккуратно оформленную карточку.

Пока здесь нет ничего похожего на сложную разработку. Но именно из таких маленьких действий собираются большие программы. Поэтому важно с самого начала понять, что происходит на каждом шаге, а не просто запомнить несколько строк кода.

## Первая программа

Самый маленький полезный пример выглядит так:

``` csharp
Console.WriteLine("Добро пожаловать в игру!");
```

`Console.WriteLine` выводит текст в консоль и после этого переводит курсор на новую строку.

Если перевод строки не нужен, используется `Console.Write`:

``` csharp
Console.Write("Введите имя: ");
```

Разница между двумя методами маленькая, но на консольных программах она заметна. С `WriteLine` следующий вывод начнётся с новой строки, а с `Write` пользователь сможет написать ответ сразу после приглашения.

## Ввод данных

Чтобы получить строку от пользователя, используется `Console.ReadLine()`.

``` csharp
Console.Write("Введите имя: ");
string name = Console.ReadLine();

Console.WriteLine($"Игрок: {name}");
```

Программа остановится на `ReadLine` и будет ждать, пока пользователь что-нибудь введёт и нажмёт Enter.

Здесь появилась переменная `name`. Переменная — это имя, под которым программа хранит некоторое значение. В данном случае она хранит имя игрока.

Название переменной должно объяснять, что внутри неё лежит. `name` или `playerName` помогают понять код, а `x` — только заставляют вспоминать, что автор имел в виду.

## Любой ввод сначала является строкой

Это правило нужно запомнить отдельно:

> Всё, что пользователь вводит через `Console.ReadLine()`, приходит в программу как текст.

Даже если пользователь написал `25`, программа сначала получает строку из двух символов: `'2'` и `'5'`. Само по себе это ещё не число, с которым можно выполнять арифметику.

Поэтому такой код не сработает:

``` csharp
string level = Console.ReadLine();
Console.WriteLine(level + 1);
```

Переменная `level` содержит строку. Программа не может прибавить число к тексту.

Нужно явно преобразовать строку в `int`:

``` csharp
Console.Write("Введите уровень: ");
int level = int.Parse(Console.ReadLine());

Console.WriteLine($"Следующий уровень: {level + 1}");
```

`int.Parse` читает текст и пытается превратить его в целое число. Если ввести `25`, в переменной окажется число 25. Если ввести `двадцать пять`, преобразование завершится ошибкой: компьютер не обязан угадывать, что именно мы имели в виду.

## Строки и вставка значений

Строка — это текст. Текст можно хранить в переменной, объединять и вставлять в готовое сообщение.

``` csharp
string playerName = "Artemis";
int level = 12;

Console.WriteLine("Игрок: " + playerName);
Console.WriteLine($"Уровень: {level}");
```

В первом случае строки соединяются оператором `+`. Во втором используется интерполяция строк: перед кавычками ставится `$`, а значения помещаются в фигурные скобки.

Для сообщений, в которых смешаны текст и несколько значений, интерполяция обычно читается проще:

``` csharp
Console.WriteLine($"{playerName} достиг {level} уровня");
```

## Собираем игровой профиль

Теперь все части можно соединить:

``` csharp
Console.Write("Имя игрока: ");
string name = Console.ReadLine();

Console.Write("Уровень: ");
int level = int.Parse(Console.ReadLine());

Console.WriteLine();
Console.WriteLine("===== ПРОФИЛЬ =====");
Console.WriteLine($"Имя:    {name}");
Console.WriteLine($"Уровень: {level}");
Console.WriteLine("===================");
```

Программа пока небольшая, но в ней уже есть законченный сценарий:

1. вывести приглашение;
2. получить ввод;
3. сохранить его в переменной;
4. преобразовать число;
5. вывести результат.

Такой порядок действий полезно замечать в любой задаче. Если вы сначала разберёте сценарий словами, код обычно становится значительно проще.

## Что может пойти не так

Главная проблема этого примера — некорректный ввод. Пользователь может нажать Enter, не введя имя, или вместо уровня написать слово.

На этом этапе не обязательно сразу строить идеальную систему обработки ошибок. Но важно понимать границу ответственности программы: `int.Parse` подходит, когда мы уверены, что строка содержит целое число. Если такой уверенности нет, позже понадобится более безопасный вариант — `int.TryParse`.

Пока достаточно не прятать проблему за магией и проверить программу на разных значениях самостоятельно.

## Итог

`Console.Write` и `Console.WriteLine` выводят данные в консоль.

`Console.ReadLine()` получает от пользователя строку.

Переменная хранит значение под понятным именем.

Ввод из консоли всегда нужно считать текстом, даже если пользователь набрал число.

`int.Parse` преобразует строку в целое число, но ожидает корректный ввод.

Интерполяция `$"...{value}..."` помогает составлять читаемые сообщения из текста и значений.

Первая лабораторная — это не соревнование по украшению консоли. Её смысл в том, чтобы научиться провести данные через программу от ввода до понятного результата.
