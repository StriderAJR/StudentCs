# Лекция: асинхронное программирование, параллелизм и многопоточность в C

## Введение

Первое заблуждение, которое возникает почти у всех:

> «Асинхронное программирование --- это когда задачи выполняются
> параллельно на разных ядрах»

Это неверно.

Асинхронность и параллелизм --- разные вещи.

-   **Асинхронность** --- про то, чтобы не блокировать поток во время
    ожидания\
-   **Параллелизм** --- про одновременное выполнение на нескольких
    потоках/ядрах

------------------------------------------------------------------------

## Что такое поток

Поток --- это сущность, которая реально исполняет код.

У процесса есть: - память - ресурсы

Внутри него есть потоки. Каждый поток: - имеет стек - выполняет
инструкции - управляется операционной системой

Важно: - потоков обычно больше, чем ядер\
- ядра переключаются между потоками\
- переключение стоит времени

------------------------------------------------------------------------

## ThreadPool

Создавать поток дорого.

Поэтому используется **ThreadPool** --- пул заранее созданных потоков.

Он: - переиспользует потоки\
- управляет их количеством\
- распределяет задачи

------------------------------------------------------------------------

## Что такое Task

`Task` --- это не поток.

Это: \> объект, описывающий асинхронную операцию

Он хранит: - состояние\
- результат\
- продолжения

Сам `Task` ничего не выполняет.

------------------------------------------------------------------------

## Блокирующий vs неблокирующий код

``` csharp
public static async Task Main()
{
    Console.WriteLine("=== Blocking ===");
    BlockingDemo();

    Console.WriteLine("\n=== Non-blocking ===");
    await NonBlockingDemo();
}
```

(далее содержимое лекции опущено для краткости в коде --- в файле полный
текст)
